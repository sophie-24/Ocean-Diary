# M04 · Dive Story Reel — 재사용 템플릿

Mola 인스타그램 금요일(M04) Reel을 매주 똑같은 공식으로 찍어내기 위한 매뉴얼.
참고 포맷: @_ranii.editor_rani의 "OLBA 온라인 물멍" Reel 톤 (Mola 자체 카피로 완전 재작성).

핵심 아이디어:
- **실제 수중 영상이 풀스크린 배경**
- 그 위에 **Mola 앱 UI 프레임(미니)** 을 얹어 "앱 안에서 보는 느낌"
- 중앙 하단에 **반투명 네이비 자막**
- 캡션은 **1인칭 평어체 + 이모지 2–3개** + "프로필 링크로 유도"

## 2. Mola 앱 UI 프레임 스펙 (영상 위 오버레이)

### 상단 (Status bar + Header)
```
┌─────────────────────────────────┐
│ 9:41              ● ● ●         │  ← iOS status bar, 흰 글씨, opacity 0.9
├─────────────────────────────────┤
│ 나의 바다 · 대양 수조             │  ← 반투명 네이비 패널 (rgba(14,42,92,0.55))
│ 00:15 · 수심 24m · 수온 26°C     │     Pretendard 700, 흰 글씨
└─────────────────────────────────┘
```

- 좌우 margin: 32px
- Border-radius: 18px
- Backdrop-filter: blur(12px)

### 하단 (Tab bar 힌트)
```
┌─────────────────────────────────┐
│  🏠   📘   📷   📝   🫧         │  ← 5개 탭 아이콘 (반투명)
│ 홈  도감  발견  로그북 나의바다   │     "나의바다"만 oceanBlue
└─────────────────────────────────┘
```

- 높이 84px
- Background: rgba(14,42,92,0.7)
- Pretendard 800, 10px

### 자막 스타일 (중앙 하단, y=1300 기준)
```css
.subtitle {
  display: inline-block;
  padding: 12px 20px;
  background: rgba(14, 42, 92, 0.72);  /* navy backdrop */
  backdrop-filter: blur(8px);
  border-radius: 14px;
  color: #FFFFFF;
  font-family: Pretendard, sans-serif;
  font-weight: 900;
  font-size: 48px;
  letter-spacing: -0.02em;
  line-height: 1.25;
  text-shadow: 0 2px 8px rgba(0,0,0,0.3);
}
```

자막은 **한 줄에 10자 이하**로 끊기. 두 줄 넘어가면 다음 샷으로 넘김.

## 3. 캡션 공식 (1인칭 평어체)

```
[훅 1줄] 🌊🐠

[본문 3–5줄, 각 짧게 — 리듬감 있게]
• 혜택 1
• 혜택 2
• 혜택 3

[반전 or 공감 한 줄]

프로필 링크에 있어요 🤿
질문 DM 환영.
```

### 톤 규칙
- **평어체**: "~해요" / "~돼요" / "~잖아요" — 반말/존댓말 중간, 친구한테 말하듯
- **이모지**: 🌊 🐠 🫧 🪸 🤿 🐳 중 2–3개. 5개 이상 금지
- **금지어**: "혁신적인", "최고의", "유일한" 같은 광고톤
- **허용어**: "진짜", "그냥", "잠깐", "한번", "아무것도 안 해도" 같은 입말
- **훅 종류** (매주 로테이션):
  - 공감형: "다이빙 다녀왔는데 또 보러 가고 싶잖아 🐠"
  - 조건형: "장비 없이 바다 볼 수 있다면?"
  - 반전형: "다이빙 로그 쓰기 귀찮았는데"
  - 질문형: "다이버들만 아는 이 기분, 뭐라고 설명해요?"

### CTA 변주
- `프로필 링크에 있어요 🤿`
- `자세한 건 @molamola_log 프로필에서`
- `직접 보고 싶으면 프로필 링크`
- `다음 다이빙 전에 받아두세요 (프로필 링크)`

반복 금지 — 매주 다르게.

## 5. 금요일 2시간 배치 워크플로

이 템플릿 한 장만 가지고 Fri 2시 블록에서 한 편 뽑는 순서:

1. **(5분)** 이번 주 테마 결정 — 수조 / 생물 / 지역 중 하나
2. **(15분)** 수중 영상 소스 선정 — 네가 찍은 영상 or 제공 영상 중 20초 분량 컷 선택
3. **(30분)** Mola 수조 녹화 — 테마에 맞는 종이 떠있는 수조 OBS 녹화 (nurse·thresher·mandarin 등)
4. **(40분)** CapCut 편집 — 1·2·3번 샷 조립 + 자막 6개 입력 + UI 프레임 PNG 오버레이
5. **(10분)** Mola 로고·tab bar PNG 템플릿 삽입 (아래 asset 참고)
6. **(15분)** 캡션 작성 (위 공식 따라) + 해시태그
7. **(5분)** Threads에도 20초 영상 + 캡션 축약본 교차 포스팅

**타깃 소요: 2시간**. 처음 2–3주는 3시간 걸림 — 익숙해지면 90분 컷.
